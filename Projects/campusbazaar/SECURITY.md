# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security problems.**

Report privately via one of the following channels:

- **Email:** vinaykumar.dev@proton.me (replace with your real address)
- **GitHub Security Advisories:** [Open a private advisory](https://github.com/vinaykumar955/Main/security/advisories/new) on the parent monorepo.

Include the following where possible:

- A clear description of the issue and its impact
- Steps to reproduce (proof-of-concept code, screenshots, or a recorded session)
- Affected commit SHA / file path
- Any suggested remediation

You should receive an acknowledgement within **72 hours**. A triage decision
(fix / accept / decline) is typically communicated within **7 days**.

## Scope

This is a student portfolio project. The application is **not intended for
production use** and does not store or process real personal data. Even so,
report anything that looks off — we treat it seriously.

## Disclosure Policy

We follow a **coordinated disclosure** model: please give us a reasonable
window (target: 30 days) to investigate and patch before publishing details.
